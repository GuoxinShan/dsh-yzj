# 金蝶标准会议纪要模板（④期，spec §16.1 ④-b）

> 用途：会议转录 → 标准纪要 → 入知识库 → 「下一步」挂事项。四段式是硬结构（目标/内容/共识/下一步），与 真机实验第 0 波人工基线同构。
> 落点默认：「我的知识/<项目父目录>」（如「830实验·共识」）;import 的 content 不得以与 fileName 相同的一级标题开头（标题会重复）。

```markdown
> 会议时间:YYYY-MM-DD HH:mm(时长) | 来源:<转录文件名/链接> | 参会:<人名列表>

## 目标
这次会要解决什么/对齐什么(一两句)。

## 内容
讨论了什么:分主题列要点,保留关键数据/对比/案例原话(转述要忠于原意,不虚构)。

## 共识
明确达成的一致(拍板的事);分歧若未收敛,写「未收敛:<争点>」,不要假装有共识。

## 下一步
- 行动项:负责人 + 时限(能识别就写,识别不了写「未指派」)
```

写作纪律:
- 四段齐全、顺序不变;没有共识就如实写「无」,不凑数。
- 「下一步」里的每条行动项,在纪要入库后由 agent 征询用户:「要落成待办/挂到哪个事项吗?」——用户发话才落,一批一次确认(决策 28);挂事项走 yzj_advance_feed(refs=[纪要 docId],纯追加静默)。
